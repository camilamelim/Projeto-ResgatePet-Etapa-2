# ResgatePet - Plataforma Web para ONGs (Etapa 2)

## 📌 Sobre o Projeto
Esta é a **segunda etapa do projeto ResgatePet**, onde a aplicação evolui de um site estático para uma **plataforma dinâmica**, com integração entre frontend, lógica em Python e banco de dados.

O objetivo continua sendo conectar ONGs, voluntários e adotantes, mas agora com uma estrutura mais próxima de sistemas reais utilizados no mercado.

---

## 🚀 Evolução da Etapa 2
Nesta etapa, o projeto passou por uma grande evolução:

🔹 Transformação de páginas estáticas em **páginas dinâmicas com Python**  
🔹 **Integração com banco de dados** para gerenciamento de informações  
🔹 Organização do sistema em múltiplos módulos (estrutura mais profissional)  
🔹 Separação de componentes como **cabeçalho e rodapé reutilizáveis**  

---

## 🎯 Funcionalidades

🔹 **Home (Início)**  
Apresentação da plataforma e destaques

🔹 **Adoção de Animais (Dinâmico)**  
- Exibição de animais cadastrados  
- Dados carregados a partir do banco de dados  
- Páginas individuais para cada animal  

🔹 **Detalhes dos Animais**  
- Informações específicas (nome, características, etc.)  
- Conteúdo dinâmico baseado nos dados armazenados  

🔹 **Resgates**  
Histórias e informações sobre animais resgatados  

🔹 **Blog**  
Conteúdo informativo sobre cuidados com pets  

🔹 **FAQ**  
Dúvidas frequentes  

🔹 **Vacinação**  
Informações sobre saúde animal  

🔹 **Portfólio**  
Apresentação dos desenvolvedores

## 🗄️ Integração com Banco de Dados

Um dos principais avanços desta etapa foi a implementação da **integração com banco de dados**, tornando o sistema mais dinâmico e funcional:

🔹 As informações dos animais são armazenadas e recuperadas do banco  
🔹 A página de adoção passou a exibir dados **dinamicamente**  
🔹 Possibilidade de atualização dos dados sem alteração direta no código  
🔹 Separação entre **camada de dados e interface**  
🔹 Estrutura mais próxima de aplicações reais do mercado  

---
